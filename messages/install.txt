Thanks for installing SyncSettingsReborn

SyncSettingsReborn is a maintained revival of the original "Sync Settings"
plugin (https://github.com/mfuentesg/SyncSettings), which is no longer
updated. It lets you synchronize your Sublime Text settings across multiple
devices, powered by GitHub Gists.

Automatic migration from the old package

- On first run, your `gist_id` and `access_token` (and proxy / include-exclude
  settings) are copied automatically from the old `SyncSettings.sublime-settings`
  file. You should not need to re-enter them.
- After confirming everything works, you can safely uninstall the old
  "Sync Settings" package.

Getting started

1. Run `SyncSettingsReborn: Edit User Settings`
2. **if** *you already have a gist?*
    1. Copy the `gist id` (`https://gist.github.com/<username>/<gist id>`) and put it in the `gist_id` setting.
    2. Run `SyncSettingsReborn: Download` to retrieve your backup.
3. **else**
    1. Create an access token at https://github.com/settings/tokens/new with the `gist` scope checked.
    2. Put the token in the `access_token` setting.
    3. Run `SyncSettingsReborn: Upload` (it creates a new Gist the first time, then updates it on later runs).

Other sync methods (no GitHub account needed)

- `Backup to Zip` / `Restore from Zip`: offline portable archive of your
  Packages/User folder.
- `Backup Package List`: back up just the installed-package list.
- `Sync Online` (`Define Folder` / `Push` / `Pull`): sync a zip through a
  Dropbox / Google Drive / OneDrive folder.

Docs: README.md (English) / README.zh-CN.md (简体中文) in the package folder
or at https://github.com/ZhangMing520/SyncSettingsReborn#readme

Requires Sublime Text 4 (build 4050 or newer).

Issues

If you hit an error or unusual behavior, please report it at
https://github.com/ZhangMing520/SyncSettingsReborn/issues, and run
`SyncSettingsReborn: Show Logs` to attach the relevant log output.

You are welcome to contribute!
